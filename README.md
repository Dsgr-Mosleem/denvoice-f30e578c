# Denvoice

Buatkan web invoice generator untuk brand saya:

Nama brand: DESIGNER_MOSLEEM
Jasa: Desain grafis (poster, undangan, infografis, kartu ucapan, sertifikat, dll)
Nomor telp: +62 899-3966-234
Alamat: Imogiri, Bantul, Yogyakarta, IDN
Identitas visual: Biru gradient (deep navy dan electric blue gradient) menggunakan logo yang terlampir.

Fitur yang harus ada:
- Otomatis penomoran invoice urut (INV-0001, INV-0002, dan seterusnya)
- History invoice client (riwayat invoice tersimpan, filter status lunas/belum, pencarian)
- Form input item jasa desain dengan kolom harga dan diskon %
- Preview invoice live dengan tampilan profesional khas studio desain
- Ekspor / download PDF invoice ukuran standar cetak A4
- Tombol kirim ringkasan invoice langsung ke WhatsApp klien
